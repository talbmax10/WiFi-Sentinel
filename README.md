# WiFi Sentinel

تطبيق Android تجريبي بواجهة داكنة عربية، لتقييم قوة كلمة مرور شبكة تملكها وإرشادات تدقيق إعدادات الراوتر.

## المزايا
- تحليل محلي تقريبي لقوة كلمة المرور.
- إرشادات لتأمين إعدادات الراوتر.
- لا توجد صلاحيات شبكة، ولا إرسال للبيانات، ولا اتصال بالراوتر.
- لا يتضمن تخمين كلمات المرور أو محاولة تسجيل الدخول.

## بناء APK بواسطة GitHub Actions
1. افتح تبويب **Actions**.
2. اختر **Build WiFi Sentinel APK** ثم **Run workflow**، أو ادفع commit جديداً.
3. افتح تشغيل workflow الناجح، ثم نزّل artifact باسم **WiFi-Sentinel-debug-apk**.
4. فك ضغطه لتحصل على `app-debug.apk`.

## البناء محلياً
يتطلب JDK 17 وAndroid SDK وGradle:
```bash
gradle assembleDebug
```

ملاحظة: APK الناتج نسخة debug غير مخصصة للنشر في Google Play. مؤشر القوة إرشادي وليس اختباراً تشفيرياً شاملاً.
